## 📌 Project Overview

This project analyses electric vehicle population data to understand vehicle distribution by location, identify popular manufacturers and vehicle types, and examine model trends.

---

## ❓ Problem Statement

To analyse electric vehicle distribution by location, identify popular manufacturers and vehicle types, and examine model trends to understand electric vehicle adoption patterns.

---

## 🎯 Objectives

- Analyse electric vehicle distribution by location.
- Identify popular vehicle manufacturers.
- Compare different electric vehicle types.
- Examine vehicle model trends.
- Understand patterns in electric vehicle adoption.

## 📂 Dataset Information

The project uses an electric vehicle population dataset to explore vehicle distribution and characteristics.

The dataset includes information such as:

- 🏭 Vehicle manufacturer

- 📅 Model year
- 🔋 Electric vehicle type
- ⚡ Electric range

## 🔄 Project Workflow

1. **Data Collection:** Obtain the electric vehicle dataset.
